# Security Policy

## Supported Versions

Only the latest published release of `@elrayes/dynamic-form-builder` receives security fixes. Please upgrade to the latest version before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this package, please **do not open a public GitHub issue**.

Instead, report it privately using one of the following:

- **GitHub Security Advisories** (preferred): [Report a vulnerability](https://github.com/Ahmed-Elrayes/dynamic-form-builder/security/advisories/new)
- **Email**: [ahmedwaill63@gmail.com](mailto:ahmedwaill63@gmail.com)

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof-of-concept
- The affected version(s)

You can expect an initial response within **5 business days**. If the report is confirmed, a fix will be prioritized and a new version published as soon as possible, with credit given to the reporter (unless anonymity is requested) in the release notes. If the report is declined, you'll receive an explanation of why it isn't considered a vulnerability or isn't in scope for this package.
